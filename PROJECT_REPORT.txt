一、项目目标
--------------------------------------------------------------------------------
构建一个由 LightGBM 模型驱动的加密量化交易网关: 从 OKX 永续合约获取实时数据
-> 模型打分 -> 生成 BUY 信号 -> 模拟仓位跟随 + 计算 PnL -> 邮件提醒,
并配备专业的交易终端前端。

二、系统架构
--------------------------------------------------------------------------------
OKX 永续 API -> mihomo 代理(127.0.0.1:7891) -> LiveFeed -> SignalEngine(LightGBM 183棵树 v49)
                                                          |
                                                          |-> signal_weights() -> BUY/HOLD 信号
                                                          |-> PaperTrader(模拟仓位+PnL)
                                                          +-> notify.py(SMTP提醒)
                                        FastAPI 网关 (127.0.0.1:8321)
                                                          |
                                        前端 index.html (Binance Pro风格)

四、扩展币种回测实验(关键决策依据)
--------------------------------------------------------------------------------
背景: 模型训练宇宙固定 15 币(coin 是 categorical 特征)。新币用模型得到固定
默认值 0.3109(无区分度, 实测验证)。

实验: 加载 OKX 69 币数据 -> 现有模型打分 -> 按成交量排序 -> 回测对比

| 宇宙        | 币数 | sharpe | return | drawdown |
|-------------|------|--------|--------|----------|
| 模型15币    | 15   | 5.636  | 7.096  | 0.175    |
| 成交量前15  | 15   | 3.169  | 1.438  | 0.129    |
| 成交量前30  | 30   | 2.888  | 1.088  | 0.186    |
| 成交量前50  | 50   | 3.238  | 1.540  | 0.157    |
| 全部69币    | 69   | 5.852  | 6.360  | 0.136    |

混合模式(模型币=模型概率 + 新币=动量排名补充): 成交量前50 sharpe 3.498,
远低于模型币 5.636。

结论: 模型 15 币贡献全部 alpha。新币要获得真实模型概率必须重新训练。

七、ATR 动态止盈止损改造 — 已完成 2026-08-24
-------------------------------------------------------------------------------
背景: 原策略止盈止损为固定值 (SL=10%/TP=12%), 无法自适应不同币种波动率。

1. 训练脚本新增 sl_tp_mode 字段 ("fixed" | "atr"):
   - fixed: 固定百分比 (约束到真实范围 0.5%-6% 止损 / 1%-12% 止盈)
   - atr: ATR 倍数 (0.5-3×ATR 止损 / 1-5×ATR 止盈, 自适应波动率)
2. 回测/GA/变异/修复逻辑全部支持 ATR 模式
3. 修复 strategy_context_features() 缺 atr → OOF 缺 ta_atr_24 (导致 ATR 从未生效)
4. 迭代: v45(return-fitness 淘汰ATR) → v46(Sharpe-fitness) → v47(OOF含ATR)
   → v48(约束fixed, ATR入选12/15但倍数5.75×过宽致342x操纵)
   → v49(收紧ATR到0.5-3×/1-5×, 止损真实触发)
5. ✅ v49 成果: ATR 模式入选 12/15, stop=2.95×ATR/take=4.79×ATR,
   stop_hits=69/take_hits=42 (真实触发), WF IR 1.33, 显著性 PASS
6. ✅ 网关 signals.py 同步: per-coin ATR 动态止盈止损 (回写 ta_atr_24)
7. ✅ 部署 v49 + 重启验证: 实时信号 per-coin 止盈止损各异
   (TRX 1.6%/2.6%, BTC 3.0%/4.8%, TIA 10.4%/16.9%)
