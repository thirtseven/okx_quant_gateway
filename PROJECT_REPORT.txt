一、项目目标
--------------------------------------------------------------------------------
构建一个由 LightGBM 模型驱动的加密量化交易网关: 从 OKX 永续合约获取实时数据
-> 模型打分 -> 生成 BUY 信号 -> 模拟仓位跟随 + 计算 PnL -> 邮件提醒,
并配备专业的交易终端前端。

二、系统架构
--------------------------------------------------------------------------------
OKX 永续 API -> mihomo 代理(127.0.0.1:7891) -> LiveFeed -> SignalEngine(LightGBM 64棵树)
                                                          |
                                                          |-> signal_weights() -> BUY/HOLD 信号
                                                          |-> PaperTrader(模拟仓位+PnL)
                                                          +-> notify.py(SMTP提醒)
                                        FastAPI 网关 (127.0.0.1:8321)
                                                          |
                                        前端 index.html (Binance Pro风格)

四、扩展币种回测实验(关键决策依据)
--------------------------------------------------------------------------------
背景: 模型训练宇宙固定 15 币(coin 是 categorical 特征)。新币用模型得到固定
默认值 0.3109(无区分度, 实测验证)。

实验: 加载 OKX 69 币数据 -> 现有模型打分 -> 按成交量排序 -> 回测对比

| 宇宙        | 币数 | sharpe | return | drawdown |
|-------------|------|--------|--------|----------|
| 模型15币    | 15   | 5.636  | 7.096  | 0.175    |
| 成交量前15  | 15   | 3.169  | 1.438  | 0.129    |
| 成交量前30  | 30   | 2.888  | 1.088  | 0.186    |
| 成交量前50  | 50   | 3.238  | 1.540  | 0.157    |
| 全部69币    | 69   | 5.852  | 6.360  | 0.136    |

混合模式(模型币=模型概率 + 新币=动量排名补充): 成交量前50 sharpe 3.498,
远低于模型币 5.636。

结论: 模型 15 币贡献全部 alpha。新币要获得真实模型概率必须重新训练。
